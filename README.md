


# BookHive Library

It is a library website, where you can find a lot of collection of books in several topics.

1 You can borrow to read .

2. You can also add your collection.

3. You can update information about your own collection.

4. If you want you can also return your collection completely, its your own coice .

5. you can also observe a avialable copies of a collection, if its copies are up to zero you can't borrow.

Only authenticated user can add collection, delete collection or update collection and even authentication is needed for borrowing a book , so it is going to be more suitable to be authenticated first
